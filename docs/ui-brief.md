# UI 工作简报（新会话从这里开始）

> 目的：把 UI 的目标、硬约束、已否决方向固定下来，避免每个会话各做一套。
> 读完这份再动手；与本文件冲突的想法，先问，不要直接做。

---

## 1. 硬约束（不可改）

1. **保留现有三栏骨架**：左侧栏（游戏内导航）+ 中间内容 + 右侧栏。
   - **不允许**把左侧栏换成顶部横向 tab。
   - **不允许**在某个页面单独丢弃左栏（全站骨架必须一致）。
2. **全站一套外壳**：wiki 列表页、实体详情页、攻略页、游戏 Hub 页、工具页共用同一 masthead / 面包屑 / 侧栏 / 页脚。
3. **不改结构以外的既有契约**：URL 形状、数据契约、构建流程、路由不改。
4. **明暗双主题必须同时成立**，不能只做一套再补另一套。
5. **广告位**：每类页面固定 2 个手动位，容器高度写死（90 / 250），加载不产生位移。
6. 改 UI 只动样式与展示组件，不顺手重构业务逻辑。

---

## 2. 已定方向（可以在此基础上细化，不要推翻）

- 语气：**资料/仪器感**，不是游戏广告牌。
- 数字：等宽、右对齐、单位在表头。
- 形状：圆角 0（广告框可 2px），**无阴影**，层次靠 1px 线。
- 强调色：**一个**（当前候选墨绿 `#0F655D` / 暗色提亮 `#3FBFAD`），稀有度色是唯一例外。
- 间距：4 基数 / 8 节奏；表格行高桌面 38–40、移动 52。
- 默认模式：深色为默认、浅色可切（**待用户最终确认**）。

## 5. 任务顺序（一次只做一件）

1. **定 token**：把浅色/深色两套值落成 CSS 变量，产出一张规格页（含对比度检查）。
2. **列表页**：三栏骨架 + 表格 + 稀有度标识 + 双广告位。
3. **详情页**：标题区 + infobox + 来源表 + 相关。
4. **游戏 Hub 页**：数据条 + 三条主入口 + 最近更新。
5. **攻略页**：正文宽度 + 目录 + 摘要块。
6. **移动端**：按 `wf4` 的折叠顺序逐页过。
7. **组件抽取**：把重复出现的块抽成组件，同一份样式两处不复制。

---

## 6. 每个任务的验收标准

1. 三栏骨架未变（与 `wf1/wf2/wf3` 对照）；
2. 明暗两套都出图，且对比度 ≥ 4.5:1（正文）；
3. 桌面 1440 + 移动 390 两档，键盘焦点可见；
4. 广告位高度固定，悬停/选中状态不产生位移；
5. 出 **1:1 全尺寸**截图（不要缩略拼图），并附一句"这轮只改了什么"。

---

## 7. 工作方式（防止方向漂移）

- **每轮只改一个杠杆**，改完先给 1:1 截图，等确认再下一步。
- **不做"并列三个方向"的探索**，除非用户明确要求；默认给一个方案 + 一个可替换点。
- 每做一个决定，写进 §8。
- 用户说"不行"时，先问"是骨架、颜色、字、还是间距"，不要整体重做。

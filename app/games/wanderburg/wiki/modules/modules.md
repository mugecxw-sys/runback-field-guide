# Top-Slot Modules

## Archer Tower

Archer Tower fires automatic arrows at nearby enemies and has an Arrow Rain active ability.

## Cannon Tower

Cannon Tower's automatic attack targets a strong nearby enemy; its active ability fires a barrage.

## Fire Mage

Fire Mage fires automatic fire projectiles and has an active ring-of-fire ability. Base values: **125 active / 2.5 automatic**, with **30s active cooldown / 10s automatic cooldown**.

## Lightning Mage

Lightning Mage attacks nearby enemies with lightning and stun effects. Its automatic attack has **7 base targets**, and upgrades can add more targets per attack. Base values: **150 active / 20 automatic**, with **60s active cooldown / 2s automatic cooldown**.

## Top Mortar

Top Mortar's automatic attack bombards nearby enemies; its active ability fires a volley into an area behind the vehicle. Base values: **70 active / 70 automatic**, with **40s active cooldown / 2.5s automatic cooldown**.

# Side-Slot Modules

## Arms

Arms strikes enemies and blocks projectiles. Its active ability enters a bashing frenzy. Base values: **40 active / 40 automatic**, **30s active cooldown**, and **2.5s automatic cooldown**.

## Cannon

Cannon fires at nearby enemies and its active ability fires a broadside. Base values: **30 active / 15 automatic**, with **15s active cooldown / 3s automatic cooldown**.

## Side Ballista

Side Ballista fires automatic arrow volleys and has a large active Ballista attack. Base damage and cooldown values are not listed.

## Side Barracks

Side Barracks automatically spawns allied troops; its active ability summons additional troops and buffs them. Available values: **3 automatic base damage**, **60s active cooldown / 12s automatic cooldown**. No active base-damage value is listed.

## Side Flamethrower

Side Flamethrower attacks beside the vehicle with an active side-flame attack and recurring automatic fire projectiles. Base values: **30 active / 50 automatic**, with **35s active cooldown / 4.5s automatic cooldown**.

# Front-Slot Modules

## Force Mage

Force Mage pushes nearby enemies away and fires magic tornadoes from the front. Its active ability cancels incoming projectiles. Base values: **20 active / 80 automatic**, with **30s active cooldown / 4s automatic cooldown**.

## Front Barracks

Front Barracks spawns Biker Knights. Its active ability performs a larger cavalry summon, while its automatic behavior produces allied units. Active base damage is **250**; automatic base damage is **5**. Cooldowns: **45s active / 10s automatic**. Allied units are immune to fire, stun and knockback.

## FrontCannon

FrontCannon is a forward-facing long-range Cannon with a stronger active cannonball and smaller automatic cannonballs. Base values: **150 active / 7 automatic**, with **10s active cooldown / 2s automatic cooldown**.

## RAM

RAM deals collision damage based on speed, and its active ability increases ramming performance. Active cooldown: **15s**. Collision damage depends on speed.

## Teleporter

Teleporter moves the vehicle forward. Its active teleport damages the arrival area; its automatic attack fires magic projectiles from the front. Base values: **100 active / 15 automatic**, with **20s active cooldown / 5s automatic cooldown**.

# Back-Slot Modules

## Catapult

Catapult creates pestilence zones behind the vehicle. Its active ability creates a larger zone and its automatic attack produces smaller zones. Base values: **10 active / 5 automatic**, with **45s active cooldown / 2.8s automatic cooldown**.

## Companion

Companion summons a Hammer Companion that fights near the player; its active ability sends the Companion into a more aggressive state. Base values: **2 active / 100 automatic**, with **2s automatic cooldown**. No active cooldown is listed.

## Dash

Dash provides forward movement and produces flames behind the vehicle while boosting. Available values: **20 automatic base damage**, **18s active cooldown / 2.5s automatic cooldown**.

## Mine Layer

Mine Layer drops mines behind the vehicle, and its active ability creates a larger mine field. Base values: **50 active / 80 automatic**, with **40s active cooldown / 5s automatic cooldown**.

## Turret Layer

Turret Layer places friendly Ballista Turrets. Its automatic behavior places single turrets; its active ability places a group of turrets and provides a buff. Base damage and cooldown values are not listed.

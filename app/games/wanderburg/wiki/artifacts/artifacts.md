# Wanderburg Artifacts Wiki (0.9.14)

This page covers three documented Artifacts. It is not a complete Artifact list.

## Quick Artifact Reference

| Artifact | Effect / Update | Patch |
| --- | --- | --- |
| Repair Wrench | Healing changed from 25% to a flat 25 HP | 0.9.14 |
| Electric Arrow | Trigger reliability was improved | 0.9.10 |
| Tinderbox | An Artifact-specific bug was fixed | 0.9.14 |

# Repair Wrench

Hotfix 0.9.14 changed Repair Wrench healing from **25% to a flat 25 HP**. Older percentage-healing descriptions do not match this update. The patch does not give a complete tooltip or trigger condition.

# Electric Arrow

Hotfix 0.9.10 says Electric Arrow now **triggers more reliably**. It does not state a numerical trigger rate.

# Tinderbox

Hotfix 0.9.14 says a Tinderbox Artifact bug was fixed. The note does not describe the bug or give the full Artifact effect.

# Artifact Rerolls

Hotfix 0.9.10: **Every 6 unlocked Artifacts → +1 Artifact Reroll**.

Hotfix 0.9.14: A **second Artifact reroll** was added from the start.

# Artifact Rerolls vs Module Rerolls

Module progression is separate: **Every 6 unlocked Modules → +1 New Module Reroll**.

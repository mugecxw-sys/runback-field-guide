# Wanderburg Artifacts Wiki (0.9.14)

This page covers the effects, trigger conditions and numeric values shown for the 21 Starter Artifacts in Wanderburg Early Access 0.9.14.

The in-game menu is labeled “Starter Artifact,” so this list covers the current Starter Artifact selection rather than every Artifact that may appear elsewhere in the game.

## Current Starter Artifact List

| Artifact | Effect |
| --- | --- |
| Bumper | Extra melee damage based on speed |
| Campfire | Auto attacks are 50% faster while not moving |
| Cluster Core | Destroying an enemy vehicle with a cannonball creates a Bullet Star explosion |
| Couldron | Consuming units accelerates magic ability cooldowns |
| Electric Arrow | Every 30th arrow has Chain Lightning |
| Extra Rations | Crew works 10% faster |
| Fast Quiver | Killing an enemy with arrows accelerates cooldowns of all arrow abilities |
| Four Leaf Clover | Improves upgrade Luck |
| Hand Crank | Gain Nitro when consuming a unit |
| Magma Core | Cannonballs leave a fire crater when hitting the ground |
| Napalm | Enemy vehicles that die from fire leave fire craters |
| Quick Reload | Cooldowns recover 50% faster while boosting |
| Repair Wrench | Discard an upgrade to heal 25 HP |
| Reset Lever | Reset all Module cooldowns when leveling up |
| Running Shoes | Friendly units also accelerate when you boost |
| Shovel | Vehicles have a 1% chance to drop an Artifact Chest |
| Souvenir | Gain 0.75% Luck for every vehicle killed |
| Stiletto | Extra melee damage against full-health enemies |
| TAX | Enemy vehicles have a 10% chance to drop a Silver Coin |
| Upgrade Dice | Gain 3 extra Module Upgrade rerolls |
| Work Contract | When consuming a Farmer, there is a 25% chance to convert it into a Sheeprider that fights for you |

# Wanderburg Wiki & Reference

A practical reference for Wanderburg’s current Early Access build, covering the core game loop, modules, captains, artifacts, vehicles, bosses, progression, and important patch changes.

> **Current coverage:** Wanderburg Early Access 0.9.14
> **Last reviewed:** September 22, 2026
> Wanderburg is in active Early Access. Balance values and mechanics can change between hotfixes, so version-sensitive information on RUNBACK is labeled and updated when official changes are published.

## Wanderburg at a Glance

Wanderburg is a single-player action roguelike built around a moving castle.

You drive your fortress across the map, consume smaller targets, grow stronger, assemble a modular arsenal, and fight increasingly dangerous enemy fortresses.

A run is shaped by several connected systems:

- your vehicle
- your captain
- equipped modules
- artifacts and supporting effects
- upgrades gained during the run
- the biome and difficulty you choose
- the build you develop as new options appear

The important part is that these systems interact. A module that is strong in one setup may be much less useful in another, which is why RUNBACK separates raw reference information from build recommendations.

## Current Game Version

The latest official Wanderburg update covered by this reference is **Hotfix 0.9.14**.

Wanderburg is changing quickly during Early Access, and several systems have already received balance changes since the September 8 launch.

### Important 0.9.14 Changes

**Electric Mage**

Its auto attack was buffed.

The base number of targets per attack increased from:

**5 → 7**

Its upgrades can now add more targets per attack.

The update also improved the reliability of the Electric Mage's **Roaming Storm** effect.

**Artifacts**

Players now begin with a **second Artifact reroll**.

The **Repair Wrench** was changed from percentage-based healing to a flat:

**25 HP heal**

For verified Artifact effects, rerolls and patch changes, see the [Wanderburg Artifacts Wiki](/games/wanderburg/wiki/artifacts).

This is especially important when comparing older guides or builds that describe Repair Wrench as healing 25% of health.

**Allied units**

Allied units are now immune to:

- fire
- stun
- knockback

They were already invincible, but these additional immunities make their behavior more consistent.

**Boss fights**

The camera now zooms out slightly during boss encounters.

Some larger enemies also no longer take percentage-based damage from boss explosion damage.

**Overtime**

Stun resistance for Overtime enemies was adjusted.

## Changes from Hotfix 0.9.13

Hotfix 0.9.13 also changed several systems that remain relevant to the current build.

### Boss rewards

All bosses now drop at least:

**50 Silver**

Older progression information that lists smaller universal boss rewards may therefore be outdated.

### Side Arms

The Side Arms Module received an auto-attack speed buff:

**3.0 seconds → 2.5 seconds**

### Damage numbers

Wanderburg now includes an optional damage-number display.

It can be enabled from the game's settings.

This makes it easier to compare actual module performance during a run instead of judging a build only by how busy the screen looks.

### Overtime

Grassland, Desert, and Darkforest Overtime were adjusted.

The update also introduced the Epic Red Overtime enemy **Metzler** for later Overtime.

Because Overtime has already been rebalanced several times during Early Access, old Overtime strategies should not automatically be treated as current.

## Progression and Rerolls

Hotfix 0.9.10 added additional rerolls based on permanent unlock progress.

For every:

**6 unlocked Modules**

you gain:

**+1 New Module Reroll**

For every:

**6 unlocked Artifacts**

you gain:

**+1 Artifact Reroll**

Hotfix 0.9.14 later added a second Artifact reroll from the start.

This means older launch-day advice about reroll scarcity may no longer accurately describe the current progression experience.

## Modules

Modules are the main pieces of equipment attached to your castle and are a major part of how a Wanderburg build develops.

Different modules can provide direct attacks, automatic attacks, summoned units, movement tools, area damage, crowd control, or other effects.

Examples confirmed in official Early Access patch notes include:

- Electric Mage
- Fire Mage
- Force Mage
- Front Barracks
- Back Turret
- Side Arms
- Side Ballista
- Top Mortar
- Ram

RUNBACK will keep module reference data separate from build recommendations.

For a verified list of modules explicitly named in official patch notes, see the [Wanderburg Modules Wiki](/games/wanderburg/wiki/modules).

A reference page answers:

**What does this module do?**

A build guide should answer:

**When should you use it, what works with it, and how does it perform in an actual run?**

## Captains

Captains modify the way a run plays and can change the value of particular strategies.

Several captains have already been changed since launch.

Hotfix 0.9.10 adjusted:

**PatchyThePirate**

Enemy Cannon bonus damage penalty:

**50% → 25%**

**Kapitalstus Maximus**

Gold penalty:

**-30% → -15%**

**Huntress**

Extra ability cooldown:

**50% → 40%**

**Tankbert**

Nitro regeneration penalty:

**50% slower → 30% slower**

**Duelist**

Extra damage taken while boosting:

**50% → 20%**

Because captain balance is already changing during Early Access, rankings and build recommendations should always be tied to a game version.

For verified Captain patch changes, see the [Wanderburg Captains Wiki](/games/wanderburg/wiki/captains).

## Vehicles

Wanderburg builds are not defined by modules alone.

Your vehicle affects how the castle moves and which kinds of setups are practical.

RUNBACK currently treats exact vehicle statistics such as health, speed, turning values, and upgrade scaling as version-sensitive data.

Those values will be published in dedicated vehicle reference pages once they have been checked against the current client.

This avoids mixing demo-era values, launch values, and current Early Access values in the same table.

## Bosses

Bosses are major progression points during Wanderburg runs.

The most important current confirmed reward rule is:

**Every boss drops at least 50 Silver as of Hotfix 0.9.13.**

Boss health, spawn timing, map-specific scaling, and difficulty values can vary and have already been changed by Early Access balancing.

For that reason, RUNBACK does not currently present an older universal Boss HP table as current fact.

Dedicated boss pages will use version-labeled values when they can be verified against the current game build.

## How RUNBACK Handles Early Access Data

Wanderburg is still changing rapidly.

For this reference, information falls into three categories.

**Official current data**

Information directly supported by current Wanderburg patch notes or official game material.

**Current-client verified data**

Information checked directly in the current playable build.

**Version-sensitive data**

Numbers or mechanics that were valid in an earlier capture or patch but have not yet been reconfirmed.

RUNBACK does not treat conflicting or unverified numerical data as a current universal rule.

This is especially important for:

- boss health
- boss timing
- module damage
- vehicle statistics
- upgrade scaling
- artifact effects
- captain modifiers
- Overtime balance

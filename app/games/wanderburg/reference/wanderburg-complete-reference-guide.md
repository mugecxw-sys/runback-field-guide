# Wanderburg Wiki & Reference

A quick guide to Wanderburg's core systems and notable changes.

> **Current coverage:** Early Access 0.9.14. Values may change during Early Access.

## Wanderburg at a Glance

Wanderburg is a single-player action roguelike built around a moving castle. Runs combine vehicle movement, Modules, Captains, Artifacts and choices made as new upgrades appear.

## Current Version — Early Access 0.9.14

Hotfix 0.9.14 changed Electric Mage's automatic attack, added an Artifact reroll at the start, changed Repair Wrench healing, adjusted allied-unit protection and made several boss-fight changes.

## Important Current Patch Changes

### Hotfix 0.9.14

- **Electric Mage / current client name Lightning Mage:** base automatic-attack targets increased from **5 to 7**; upgrades can add more targets per attack. The update also improved the reliability of Roaming Storm.
- **Artifacts:** players now start with a second Artifact reroll. Repair Wrench changed from **25% healing to a flat 25 HP heal**; a Tinderbox bug was fixed.
- **Allied units:** immune to fire, stun and knockback.
- **Boss encounters:** the camera zooms out slightly. Some larger enemies no longer take percentage-based damage from boss explosion damage.
- **Overtime:** enemy stun resistance was adjusted.

### Hotfix 0.9.13

- Bosses now drop at least **50 Silver**.
- **Side Arm Module / current client name Arms:** base automatic-attack interval changed from **3.0 seconds to 2.5 seconds**.
- Optional damage numbers were added to the settings.
- Grassland, Desert and Darkforest Overtime were adjusted.

### Hotfix 0.9.10

- Every **6 unlocked Modules** grants **+1 New Module Reroll**.
- Every **6 unlocked Artifacts** grants **+1 Artifact Reroll**.
- Electric Arrow trigger reliability was improved, and the Rare Artifact screen softlock was fixed.
- PatchyThePirate, Kapitalstus Maximus, Huntress, Tankbert and Duelist received documented balance changes. Tankbert's current-client tooltip and the 0.9.10 patch note conflict; see Captains below.

## Progression and Rerolls

Permanent unlock progress increases rerolls separately for Modules and Artifacts: each group of **6 unlocked items** adds **1 reroll** of that type. Hotfix 0.9.14 also added a second Artifact reroll from the start.

## Modules

Modules attach to the moving castle and provide attacks or other effects. The [Wanderburg Modules Wiki](/games/wanderburg/wiki/modules) lists the **20 Modules visible in the 0.9.14 client**, their slots, current descriptions, available base values and documented patch changes. The current client calls Electric Mage **Lightning Mage**, Side Arm Module **Arms**, and Back Turret Module **Turret Layer**.

For practical decisions using confirmed Module effects, see the [Wanderburg Builds Guide](/games/wanderburg/builds).

## Captains

Captains have visible bonuses and drawbacks. The [Wanderburg Captains Wiki](/games/wanderburg/wiki/captains) covers the **14 Captains shown in the current client** and the relevant patch history.

**Tankbert value conflict:** the current-client tooltip displays **-50% Nitro Regeneration**. Hotfix 0.9.10 says the penalty changed from **50% slower to 30% slower**. The runtime value has not been independently verified, so these values remain in conflict.

## Artifacts

The [Wanderburg Artifacts Wiki](/games/wanderburg/wiki/artifacts) covers three Artifacts named in official patch notes: Repair Wrench, Electric Arrow and Tinderbox. It records the Repair Wrench change to **25 HP**, the Electric Arrow reliability fix, the Tinderbox bug fix and Artifact reroll rules.

## Bosses and Overtime

Hotfix 0.9.13 states that every boss drops at least **50 Silver**. Hotfix 0.9.14 changed the camera during boss fights and the percentage-based explosion damage taken by some larger enemies. Overtime changes include adjustments to Grassland, Desert and Darkforest, with stun resistance adjusted again in 0.9.14.
